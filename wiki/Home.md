# PCSS II Robotics

Project documentation for the website associated with Pioneer Charter School of Science II (PCSS II).

The [official website](https://www.pcssiirobotics.org/) is the source for current team, research, robot, and outreach information. This wiki explains how to develop and maintain the website.

Site author: [Aarti S Ravikumar](https://ai-aarti.com/).

## Guides

- [[Local Development]] — install dependencies and run the site locally.
- [[Deployment]] — Vercel and GitHub Pages setup.
- [[Search and Indexing]] — canonical URLs, discovery pages, and IndexNow.
- [[Arcade]] — local and online game modes.

The GitHub Pages guide is a secondary project entry point. It is marked `noindex`; use the official website when sharing or citing site content.
